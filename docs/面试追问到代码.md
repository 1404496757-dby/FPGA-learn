## 看波形的顺序

1. common：s_valid/s_ready、m_valid/m_ready、ram_count、rptr/wptr；区分预取与消费。
2. async：两个本地binary/Gray指针、同步级、full/empty、rd_valid；观察同步延迟与保守标志。
3. comm：state、qvalid/qready、SPI req/result、reply_index；暂停tx_ready后结果必须停住。
4. image：state、input_index/feed_index、i_sof/i_e、encoded_words、capture_overflow、response_length、output_crc。
5. PID：integral/previous_error、32位product、34位sum、scaled、control、saturated、m_valid。
6. PWM：phase、active_duty、pending、blank_count、两路输出；改变duty只在周期边界生效。

# 2026-10-03最终验证记录

实际使用本机Vivado 2018.3 / XSim，目标器件xc7a35tfgg484-2。下面记录均来自实际运行，不代表物理开发板已验证。

## 功能仿真

六组自检查测试全部通过：common、comm、uart_board、image、interview、spi。整体运行记录在verification_all.json；图像复位连接最后调整后，单独重新运行image，记录在verification_image.json。DELIVERY_STATUS.json合并两份记录并指向最终版本。

| 测试 | 关键验证 |
|---|---|
| common | 同步FIFO随机满空、反压、同拍进出；异步FIFO400字；40次事件CDC |
| comm | 回显/SPI/状态命令、错误校验、未知命令、输出暂停、半包超时 |
| uart_board | 完整通信顶层115200 8N1串行回显及SPI内部回环 |
| image | 四张图缓存与编码、输出暂停、CRC拒绝、强制溢出、半帧超时 |
| interview | PID有符号极值/Q8运算/限幅/输出暂停；互补PWM死区 |
| spi | CPOL/CPHA四模式，每种16个字节回环 |

图像码流由本机FFmpeg独立解码，四张图均4096像素逐一一致：

## 完整综合与实现

| 工程 | 逻辑时钟 | LUT | 寄存器 | BRAM tile | DSP | WNS/ns | WHS/ns | 默认DRC违例 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| comm | 50MHz | 345 | 379 | 0.5 | 0 | 7.949 | 0.031 | 0 |
| image | 25MHz，输入晶振50MHz | 2593 | 1238 | 14 | 0 | 19.193 | 0.048 | 0 |

BRAM tile以36Kb资源为单位，0.5对应18Kb。两个工程均完成布局布线及bitstream生成；时序报告中的无时钟寄存器、无最大延迟约束内部端点、缺失输出延迟端口均为0。UART RX与板级复位采用文档说明的异步输入例外，不能据此推断UART不存在亚稳态风险。

最终工程路径：

- 通信：builds/comm_1791034052904/jianli_comm.xpr
- 图像：builds/image_1791034419789/jianli_image.xpr

最终.bit与报告副本分别放在output/comm和output/image。较早的builds目录保留调试记录，不作为最终交付依据。

Vivado仍报告本机环境Common 17-741：本地Tcl store不可写，工具回退到安装目录。最终两个默认DRC报告均为0违例；没有压制BRAM复位警告来换取通过。

## 实际能力边界

尚未连接板卡进行物理UART传输或下载测试。SPI顶层是内部回环；JPEG-LS已验证服务模块与编码核心，但图像板级时钟IP/UART链路仍需上板。异步FIFO、事件CDC、PID、PWM是独立仿真练习，未集成进这两个板级顶层，资源及时序表不覆盖它们。

SD卡、CAN、DDR、摄像头、编码器反馈、真实电机闭环及ILA插入未在本版实现。串口客户端依赖pyserial，安装和实际COM口选择见README。
